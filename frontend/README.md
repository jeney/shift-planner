# Shift Planner – frontend

React + Vite + TypeScript, Tailwind CSS v4 + shadcn/ui, react-i18next, TanStack Query.

```bash
npm ci
npm run dev          # http://localhost:5173 (proxies /api → http://localhost:8000)
npm run lint && npm run format:check && npm run typecheck && npm test
npm run e2e          # Playwright smoke tests (builds + previews the app)
npm run gen:api      # regenerate src/api/schema.ts from openapi.json
```

- Translations: `src/i18n/locales/{en,da,hu}.json`. A unit test makes sure all three have the same keys.
- UI primitives: `src/components/ui` (generated by `npx shadcn add …`).
- API client: `src/api/client.ts` (typed with `openapi-fetch` against the generated schema).
